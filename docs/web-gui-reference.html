PS Linker — Web GUI reference

A static, self-contained portrait of the current server UI (server/store/ui/, served at http://this-host:PORT/gui/). Every screen below is rendered with the GUI's real stylesheet (ui.css, inlined) and markup copied from ui.js / manage.js / uploads.js / store.js / dock.js; the library data is the live catalog.json. Use it as the visual baseline for layout work — anything that drifts from these frames is a bug in one of the two.

Tokens: dark theme data-theme="dark" (default; a light theme overrides only the token block). Radius --radius:10px, controls --radius-sm:6px, transitions 160ms, no dependencies, no build step.

2 · Library — the app shell

Sidebar = sections() (All / Favorites / Recently Viewed, then Platforms PSP/PS3 when present, then one entry per catalog Folder, each with a count pill); foot holds Store (badge = queue activity) and Settings. Toolbar = search, sort (SORTS), ＋ Add Games. Cards come straight from catalog.json: placeholder covers are an id-hashed gradient with the title's first two letters, ☆ favours, one selected card shows the accent ring.

Cover tile, title + platform chip, “category · size”, the Version/File/ID kv grid, then the Cover and License (RAP) boxes (manage.js) and the 2-column action grid: favourite, download (straight <a download> against the share), rename, move, metadata, delete (armed twice). .rap files get a key badge 🔑 on their card (red when the license file is gone) and a dashed border.

4 · Add Games modal (uploads)

One panel, both paths: click the dashed zone, or drop files anywhere in the window (full-screen Drop to add games overlay). Files go to the library root tagged psp|ps3 and land in their tab immediately. Rows are one-at-a-time uploads in four states (Waiting / % / ✓ Added / error). When the panel closes, finished rows are discarded and the box retires — only in-flight uploads (and unseen failures) carry on in the dock.

5 · Store modal (server-side downloads)

The server's own fetcher: a live row while it works, ⬇ Download now to kick it, a queue form (URL + optional title + one-folder category), and the download history. Queue and history rows reuse the same .up-row grid as uploads.

6 · Transfers dock + toasts

The corner dock (dock.js) is one shell with an Uploads and a Store section, each collapsible; it appears only while a module has activity and retires itself a few seconds after the last transfer lands. Toasts bottom-left carry the same states (accent / green / red left rail).
